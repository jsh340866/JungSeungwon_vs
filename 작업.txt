공장 데이터흐름
 : 공장 화면에서 조회 버튼을 누르면 FactoryView가 FactoryApi를 호출하고, FactoryApi는 서버에 HTTP 요청을 보낸다. 서버는 Controller -> Service -> Repository 순으로 호출하고, Repository는 엔티티를 기준으로 DB를 조회해 결과를 Dto에 담는다. Dto는 Service를 거쳐 Controller로 돌아가 JSON으로 응답된다. client의 FactoryApi는 그 응답을 Output에 담고, Converter가 Model로 옮겨 grid에 표시한다.

폼 -> API 호출(Input) -> 서버(Controller -> Service -> Repository) -> DB
폼 ← (Output -> Model) ← 응답(DTO를 JSON으로) ← 서버(Repository Dto -> Service -> Controller)

[화면 구조]
- 업무 화면은 Form이 아니라 MesBaseView(UserControl) 상속, 띄울 때 formHelper.ShowDialogView(view)
- 생성자: InitializeComponent -> AddEventHandlers -> 단축키, 코드는 #region으로 묶음
- 입력은 TextBox 대신 DevExpress TextEdit, ButtonEdit 등 사용, LayoutControl로 배치
- control 이름은 한글+종류 (공장명Edit, 저장Button)

[C# 문법]
- 조건 검사에 is를 많이 씀: if (control is BaseEdit baseEdit) { } (type 확인과 변수 선언을 한 번에)
- 콤보박스, 목록의 정해진 선택지에는 enum 사용
- IEnumerable: 인터페이스, 하나씩 순서대로 꺼낼 수 있음.
   List와 달리 추가·삭제는 못 하지만, IEnumerable을 구현한 타입(List, 배열 등)이면 받을 수 있음
- null 가능 값은 long?, HasValue 확인 후 Value 사용

[데이터]
- 조회: Output -> Converter -> Model -> grid / 저장: 화면 -> Input -> API
- server 호출은 async/await, 로딩 표시는 ShowOverlay
- ApiResult는 IsSuccess 확인 후 Data 사용, 실패하면 Error 표시
- 저장 결과는 view.ResultOk(bool)로 전달, 성공하면 다시 조회

[Grid]
- DataSource를 get/set 속성으로 감싸고, 내용 변경 후 RefreshDataSource()
- 선택 행은 GetFocusedRow() as Model -> null 확인
- 공통 설정은 GridHelper.ApplyMesStyle (더블클릭, Enter 동작 등록)

[검사와 안내]
- 조건이 안 맞으면 message 후 return (guard clause)
- 삭제 같은 위험한 작업은 MessageView로 한 번 더 확인

[공통 기능]
- 권한은 Program.UserPermissionHelper.GetPermission(menu)로 받아 버튼에 적용
- 화면 글자를 코드로 넣을 때 languageHelper.ReplaceText (번역)
- 조회, 추가, 수정, 삭제 이력은 SystemUsageHistoryHelper
- DialogResult.Ok 안씀 ResultOk 클래스 필드에 bool type으로 get/set 만들어서 확인 
	(UserControl로 폼형태가 아니라 따로 관리해서 쓰는걸로 추정)


[공통 도구 메서드]
1. ShowOverLay : 로딩 표시하며 실행
2. ShowStatus, CMessageBox : 안내 message
3. formHelper.ShowDialogView : 화면을 창으로 띄우기
4. GridHelper.ApplyMesStyle : grid 공통 설정
5. editHelper.ApplyMesStyle : 입력란 공통 설정
6. AddShortcut : 단축키 지정
7. UserPermissionHelper.GetPermission : 권한 설정
8. languageHelper.ReplaceText : 텍스트 번역
