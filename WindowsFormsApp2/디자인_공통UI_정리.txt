============================================================
 부서사원 과제 - 공통 UI 정리 (Adobe XD 시안에서 추출)
============================================================
 출처 : 230908_과제 부서사원 (XD 공유 링크의 디자인 데이터)
 단위 : px (XD 기준 = WinForms 100% 배율 96dpi 기준, 그대로 사용 가능)
 좌표 : 대화상자 "왼쪽 위 모서리"를 (0,0)으로 한 상대 좌표


------------------------------------------------------------
 1. 색상 (Hex)  ->  WinForms: Color.FromArgb(R, G, B)
------------------------------------------------------------
 #FFFFFF  흰색      입력칸/그리드 배경, 버튼 글자        (255,255,255)
 #F3F3F3  연회색    타이틀바 배경, 읽기전용 입력칸 배경  (243,243,243)
 #ABABAB  회색      모든 테두리(1px), 회색 버튼          (171,171,171)
 #333333  진회색    기본 글자색                          (51,51,51)
 #000000  검정      화면 큰 제목(30px)에만 사용          (0,0,0)
 #0072C6  파랑      저장 버튼, 사람 아이콘               (0,114,198)
 #F4503B  빨강      필수항목 라벨, 삭제/취소 버튼        (244,80,59)
 #04BF1D  초록      화살표 표시(화면 이동 흐름 설명용, 실제 UI 아님)

 보조 (일부 아이콘): #424242 (검색/더보기 아이콘), #666666 (닫기 아이콘)


------------------------------------------------------------
 2. 글꼴
------------------------------------------------------------
 글꼴 : Segoe UI Regular (전부 동일)

  XD 크기   WinForms Font 크기   용도
  -------   -------------------   ---------------------------------
   30px      22.5pt               화면 큰 제목 ("부서사원 등록") - 설명용
   13px      9.75pt (약 10pt)     타이틀바 제목, 삭제 확인 메시지
   12px      9pt                  라벨, 버튼 글자, 그리드, 입력칸 (기본)

 * WinForms Font는 pt 단위. 12px = 9pt (96dpi 기준 px x 0.75).
 * 글자색: 기본 #333333 / 필수 라벨 #F4503B / 버튼 글자 #FFFFFF


------------------------------------------------------------
 3. 공통 부품 크기
------------------------------------------------------------
 [대화상자 테두리]
   1px 실선 #ABABAB (안쪽 정렬), 배경 흰색, 모서리 둥글기 없음

 [타이틀바]  (대화상자 맨 위, 이름: "작업메뉴")
   높이 35px / 너비 = 대화상자 너비 - 2 (테두리 안쪽 전체)
   배경 #F3F3F3, 테두리 없음
   왼쪽 사람 아이콘 24x24 (#0072C6), 위치 x=7, y=6   (메인 폼에만 있음)
   제목 글자 13px #333333, 대화상자는 왼쪽에서 약 10px 띄움
   오른쪽에 아이콘(검색/인쇄/더보기 24x24) 있으나 기능 설명 없음 -> 골격 단계에서는 생략 가능

 [입력칸 TextBox]
   높이 22px / 너비 147px (부서 폼) 또는 154px (사원 폼)
   배경 #FFFFFF, 테두리 1px #ABABAB
   읽기전용(부서명 칸 in 사원 추가/수정)은 배경 #F3F3F3
   메모 칸은 가로로 길게: 부서 폼 310px / 사원 폼 489px (높이 22px 동일)
   부서코드 칸(사원 폼)은 오른쪽 안쪽에 조회 아이콘 17x20 (오른쪽 끝에서 약 1px 안쪽)
   비밀번호는 ******** (PasswordChar = '*')

 [라벨 Label]
   입력칸 바로 위, 입력칸과 위쪽 간격 약 6px (글자 12px)
   필수 항목: 글자색 #F4503B (빨강)  / 일반 항목: #333333

 [버튼 Button]
   크기 120 x 30px, 모서리 둥글기 없음, 테두리 없음, 글자 12px 흰색
   두 버튼 사이 간격 15px, 버튼 줄은 가운데 정렬
   저장   -> 배경 #0072C6 (파랑)
   삭제   -> 배경 #F4503B (빨강)
   취소   -> 부서/사원 "추가" 창: #F4503B(빨강) / "삭제 확인" 창: #ABABAB(회색)
   닫기   -> 배경 #ABABAB (회색)   ("수정" 창, "로그인정보" 창)

 [그리드 DataGridView]
   헤더 높이 31px / 행 높이 24px / 기본 열 너비 100px
   맨 왼쪽 행 선택 열(RowHeader) 너비 20px
   모든 칸: 배경 #FFFFFF, 테두리 1px #ABABAB, 글자 12px #333333
   그리드 바깥 테두리도 #ABABAB 1px

 [크기 조절 표시]
   대화상자 오른쪽 아래 8x8 점 모양 (SizeGrip) - 선택사항

 5. 배치 규칙 예시 - "부서 추가/수정" 창 (332 x 206)
------------------------------------------------------------
   타이틀바        : (1, 1)   크기 330 x 35,  제목 "부서 추가"
   부서코드 라벨   : x=10, y 약 47~60   (빨강)
   부서코드 입력   : (10, 66)   147 x 22
   부서명  라벨    : x=175       (빨강)
   부서명  입력    : (175, 66)  147 x 22      <- 두 칸 사이 간격 18px
   메모    라벨    : x=10, 위 줄에서 53px 아래
   메모    입력    : (10, 119)  310 x 22
   버튼 1 (저장)   : (65, 160)  120 x 30
   버튼 2 (취소)   : (200,160)  120 x 30
   아래 여백       : 약 16px

 "부서 삭제" 창 (332 x 163)
   메시지 글자     : x=10, 타이틀바 아래, 13px
                     "부서코드: DEP01 / 부서명: 생산1팀 / (빈 줄) / 삭제하시겠습니까?"
   버튼 (삭제,취소): y=123, x=68 / x=203, 120 x 30

 "사원 추가/수정" 창의 입력칸 배치 (입력칸 154px, 가로 3열)
   열 x좌표 : 10 / 179 / 348        (열 간격 15px: 154 + 15)
   1행 : 부서코드(필수) | 부서명(읽기전용)
   2행 : 사원코드(필수) | 사원명(필수)
   3행 : 로그인ID(필수) | 비밀번호(필수)
   4행 : 직위           | 고용형태
   5행 : 휴대전화       | 이메일        | 메신저ID
   6행 : 메모 (가로 489px)
   버튼 : 저장(파랑) / 취소(추가: 빨강, 수정: 닫기 회색)
   행 간격 : 약 53px (라벨+입력칸 한 묶음 기준)
   * "사원 수정"은 위 목록에서 3행(로그인ID, 비밀번호)이 빠지고,
     로그인ID/비밀번호는 별도 "로그인정보" 창(메인의 [로그인정보] 버튼)에서 수정합니다.
   * 모든 좌표는 상대 값이라 WinForms Location에 거의 그대로 쓰되,
     실제 배치 후 눈으로 한 번 확인하세요.
